## 安装

先安装前置插件管理器: [Applepie Manager](https://github.com/zonemodAE/ApplepieManager)，再将以下文件复制到游戏目录（`Endfield.exe` 所在文件夹）：

```
bin/anti_afk.dll         → 游戏目录/plugin/anti_afk.dll
anti_afk_config.txt      → 游戏目录/plugin/anti_afk_config.txt
```

> 如果您**没有安装过此类型的插件**，您可能需要自行创建plugin文件夹。
