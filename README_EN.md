# Endfield AntiKick

English | [中文](README.md)

Prevents being kicked from *Arknights: Endfield* servers due to prolonged inactivity.

## Download

Required plugin manager: [Applepie Manager](https://github.com/zonemodAE/ApplepieManager)

Download the latest release from [Releases](https://github.com/Sasye/EndFieldAntiKick/releases), or build it yourself from source.

## Installation

First install the required plugin manager, [Applepie Manager](https://github.com/zonemodAE/ApplepieManager), then copy the following files to the game directory (the folder containing `Endfield.exe`):

```
bin/anti_afk.dll         → Game directory/plugin/anti_afk.dll
anti_afk_config.txt      → Game directory/plugin/anti_afk_config.txt
```

> If you **have not installed this type of plugin before**, you may need to create the `plugin` folder yourself.
